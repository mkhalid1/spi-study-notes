# 出典

このガイドに書いたSPI３の事実（構成、受検方式、検査時間、会場、規則、結果の扱いなど）は、すべて提供元であるリクルートマネジメントソリューションズの公式ページから取っています。いずれも2026年11月25日に内容を確認しました。

## 提供元：SPI３公式サイト（企業向け）

- [SPI３公式サイト トップ](https://www.spi.recruit.co.jp/)：名称の由来、1974年の誕生、利用実績（年間16,500社、276.6万人、2026年3月期実績）
- [SPI３ 採用候補者向け適性検査](https://www.spi.recruit.co.jp/spi3/)：テストの種類と実施方法の概要
- [SPI３の特長](https://www.spi.recruit.co.jp/spi3/features/)：活用場面、対策本の影響についての説明、結果の見方
- [SPI３ 大卒採用向け](https://www.spi.recruit.co.jp/spi3/service/spi3_u.html)：面接前の実施、報告書の内容、利用企業の約67%が中小企業
- [SPI３ 高卒採用向け](https://www.spi.recruit.co.jp/spi3/service/spi3_h.html)：基礎能力（総合・言語・非言語）
- [SPI３ 料金・プラン](https://www.spi.recruit.co.jp/spi3/charge/)：性格検査と基礎能力検査の説明、4つの実施方法
- [SPI３ 料金詳細](https://www.spi.recruit.co.jp/spi3/charge/charge.html)：テストの種類ごとの検査時間（このガイドでは時間だけを引用しています）
- [SPI３ よくある質問](https://www.spi.recruit.co.jp/spi3/faq/)：4つの実施方法、リアル会場の7都市と臨時会場、オンライン会場、不正行為の扱い

## 提供元：テストセンター情報

- [テストセンター情報](https://www.spi.recruit.co.jp/testcenter/)：リアル会場とオンライン会場
- [テストセンター 受検の流れ・基本情報](https://www.spi.recruit.co.jp/testcenter/about.html)：受検の流れ、推奨環境、持ち物
- [テストセンター よくある質問](https://www.spi.recruit.co.jp/testcenter/faq.html)：性格検査の期限、前回結果送信、予約・変更・遅刻・欠席、持ち物、計算機、結果の開示
- [テストセンター オンライン会場](https://www.spi.recruit.co.jp/testcenter/online.html)：オンライン会場の特徴と流れ
- [テストセンター 会場のご案内](https://www.spi.recruit.co.jp/testcenter/list.html)：会場の一覧

## 提供元：就職準備応援サイト（受検者向け）

- [適性検査「SPI」とは？](https://www.recruit-ms.co.jp/freshers/spi-001.html)：能力検査と性格検査、4つの受検方法、受検前の準備
- [SPIの性格検査とは？](https://www.recruit-ms.co.jp/freshers/spi-002.html)：約300問、質問の形式、答え方の助言
- [SPIの能力検査とは？](https://www.recruit-ms.co.jp/freshers/spi-003.html)：言語分野と非言語分野、問題例の種類、得点の見方
- [SPIのテストセンターについて](https://www.recruit-ms.co.jp/freshers/spi-006.html)：受検の流れ、前回結果送信、注意点、不正防止
- [WEBテスティングについて](https://www.recruit-ms.co.jp/freshers/spi-010.html)：受検の流れ、注意点、中断時のしくみ
- [よくあるご質問について](https://www.recruit-ms.co.jp/freshers/spi-012.html)：合格点、長文問題、制限時間、出題数、公式対策本の有無
- [SPIの開発背景と理念](https://www.recruit-ms.co.jp/freshers/spi-013.html)：1963年の開発開始、適応型テストとIRT、1999年のCBT実用化

## 検索データ

[よくある質問](faq.md)の質問は、DataForSEOのGoogle検索結果データ（日本、日本語）で、「SPI」「SPI テストセンター」の検索結果に表示された「他の人はこちらも質問」と関連検索から選びました。2026年11月25日に取得しています。

## このガイド独自の内容

次のものは公式の情報ではなく、このガイドの考え方や目安です。本文でもそのつど断っています。

- 言語・非言語を9つの問題タイプに分けた整理（市販の問題集でもよく使われる分け方で、公式の区分ではありません）
- 各問題タイプの解き方の手順、よくあるミス、1問あたりの時間の目安
- 練習問題35問（各ページ26問と診断テスト9問）。すべてこのガイドのために作ったオリジナルで、SPI３の実際の問題や、公式・市販の問題集から取ったものではありません
- 自己採点表と学習プラン

PrepClubsの模擬テストへのリンクは練習の場として紹介しているもので、PrepClubsのページはSPI３の事実の出典としては使っていません。

## 提携関係について

このガイドは独立したもので、リクルートマネジメントソリューションズとは提携しておらず、同社の承認や後援も受けていません。SPI、SPI３は、それぞれの権利者の商標です。

誤りや情報の変更に気づいた方は、[Issue](https://github.com/mkhalid1/spi-study-notes/issues)かプルリクエストでお知らせください。事実の訂正には、公式ページへのリンクを添えてください。
