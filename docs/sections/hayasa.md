# 速さ

**ひとことで言うと：** 道のり、速さ、時間の関係から、どれか一つを求める問題です。2人が出会う、追いつくといった問題もこのタイプに入ります。

非言語分野の計算問題の一つです。使う式は「道のり＝速さ×時間」の一つだけですが、**単位の換算**と**2人の速さの足し引き**でつまずく人が多いタイプです。なお、「速さ」という名前は市販の問題集でよく使われる呼び方で、公式の区分名ではありません。

## 何を測っているか

非言語分野の「数的な処理ができるか」を見る形式です。状況を図にして、どの量とどの量を組み合わせればよいかを判断する力が問われます。

## 押さえておく関係

| 求めるもの | 式 |
|---|---|
| 道のり | 速さ×時間 |
| 速さ | 道のり÷時間 |
| 時間 | 道のり÷速さ |
| 出会うまでの時間（反対方向） | 2人の間の道のり÷（2人の速さの和） |
| 追いつくまでの時間（同じ方向） | 2人の間の道のり÷（2人の速さの差） |

単位の換算もよく使います。分速を60倍すると時速（m）に、時速kmを1,000倍して60で割ると分速mになります。

## 解き方の手順

1. **単位をそろえる。** km、m、時間、分が混ざっていたら、計算の前にどれか一つにそろえます。
2. **線を一本引いて図にする。** 出発点、到着点、2人の位置を書き込むと、何を足すのか引くのかが見えます。
3. **平均の速さは「全体の道のり÷全体の時間」で出す。** 行きと帰りの速さを足して2で割るのは誤りです。
4. **2人の問題は、向きを確かめてから和か差を使う。** 反対向きなら近づく速さは和、同じ向きなら差です。

## よくあるミス

- **平均の速さを、速さの平均で出す。** 行きが時速6km、帰りが時速4kmなら、往復の平均は時速5kmにはなりません。遅いほうで走る時間が長いからです。
- **単位をそろえずに計算する。** 分速mと時速kmが混ざった式は、必ずどこかで桁がずれます。
- **池の周りの問題で、向きを読み落とす。** 「反対方向に」か「同じ方向に」かで、和と差が入れ替わります。

## 時間の目安

1問1分前後を目安にしてください（このガイドの目安で、公式の数字ではありません）。

## 練習問題

この2問は、このガイドのために作ったオリジナル問題です。SPI３の実際の問題や公式の問題例ではありません。

**問1.** A町とB町は24km離れています。A町からB町までは時速12kmで、帰りのB町からA町までは時速8kmで移動しました。往復の平均の速さは時速何kmですか。

A 時速9km　B 時速9.6km　C 時速10km　D 時速10.4km　E 時速11km

**問2.** 1周1.2kmの池の周りを、PとQが同じ地点から同時に、同じ方向に歩き始めました。Pは分速70m、Qは分速50mです。PがQに初めて追いつくのは、歩き始めてから何分後ですか。

A 10分後　B 20分後　C 30分後　D 60分後　E 120分後

<details>
<summary>解答と解説を見る</summary>

**問1：B（時速9.6km）。** 行きは24÷12＝2時間、帰りは24÷8＝3時間かかります。往復の道のりは48km、かかった時間は5時間なので、平均の速さは48÷5＝9.6で時速9.6kmです。12と8の平均の時速10kmを選ぶのが典型的なミスです。

**問2：D（60分後）。** 同じ方向に歩くので、PはQとの差を1分に70－50＝20mずつ広げていきます。PがQに追いつくのは、その差がちょうど池1周分の1.2km＝1,200mになったときです。1,200÷20＝60分後です。反対方向に歩いた場合は速さの和を使い、1,200÷120＝10分後に出会います。

</details>
