# 長文読解

**ひとことで言うと：** 数百字の文章を読み、内容と合うもの、空欄に入る語、筆者がそう述べる理由などを答える問題です。

公式の就職準備応援サイトでは、言語分野の問題例として「文章読解」が紹介されています。公式によると、長文問題はテストセンターやWEBテスティングで出題されますが、**必ず出題されるわけではありません**。受検者の回答状況に応じて問題が選ばれるしくみだからです。

## 何を測っているか

長い文章を読んで内容を理解し、要旨をつかむ力です。公式は「文章を読み解くために必要な知識や情報はすべて本文中に書かれているため、前提知識などは求められません」と説明しています。つまり、**答えの根拠は必ず本文の中にある**ということです。

出典：[就職準備応援サイト「よくあるご質問について」](https://www.recruit-ms.co.jp/freshers/spi-012.html)。2026年11月25日に確認。

## 問題の形

1つの文章に対して、複数の設問が続きます。よくある設問は次の4つです。

| 設問 | 問われること |
|---|---|
| 内容一致 | 本文の内容と合うもの、合わないものを選ぶ |
| 空欄補充 | 本文中の空欄に入る接続語や語句を選ぶ |
| 理由・指示内容 | 筆者がそう述べる理由や、「それ」が指すものを選ぶ |
| 要旨 | 筆者の考えに最も近いものを選ぶ |

## 解き方の手順

1. **設問に先に目を通す。** 何を探しながら読めばよいかが決まります。
2. **段落ごとに一言でまとめながら読む。** 「メモの役割は2つ」「記録だけでは限界」のように、メモ用紙に短く書くと、あとで戻る場所がすぐわかります。
3. **選択肢は本文と照合してから選ぶ。** 「たぶんそう書いてあった」で選ばず、根拠になる文を本文の中で指さしてから答えます。
4. **言いすぎの選択肢を疑う。** 「必要がなくなった」「〜すべきである」のように、本文より強い言い方をしている選択肢は外れであることが多いです。

## よくあるミス

- **自分の意見や常識で選ぶ。** 正しそうな内容でも、本文に書かれていなければ不正解です。
- **一部だけ合っている選択肢を選ぶ。** 前半は本文どおりでも、後半が本文と違う選択肢がよく混ざっています。
- **空欄補充で、空欄の前の一文しか読まない。** 空欄の前後の両方を読み、どんな関係でつながっているかを確かめます。
- **最初から最後まで丁寧に読み直す。** 時間が足りなくなります。段落メモを手がかりに、必要な箇所だけ戻ります。

## 時間の目安

文章を読むのに2分前後、設問1つに30秒前後を目安にしてください（このガイドの目安で、公式の数字ではありません）。パソコンで受ける方式では問題ごとに制限時間があるので、[時間配分のページ](../timing.md)もあわせて読んでおきましょう。

## 練習問題

この文章と3問は、このガイドのために作ったオリジナル問題です。SPI３の実際の問題や公式の問題例ではありません。

> 会議でメモをとる人は多いが、その目的を意識している人は意外に少ない。メモには大きく二つの役割がある。一つは、聞いた内容を後で確認するための記録としての役割である。もう一つは、書きながら話の構造を整理し、理解を深めるための道具としての役割である。
>
> 前者だけを目的にすると、人は話されたことをできるだけ多く書き写そうとする。しかし、話す速さに書く速さが追いつくことはまずない。書き写すことに気を取られ、肝心の話の流れを見失うことも少なくない。録音や議事録が手軽に残せる今、記録のためだけのメモの価値は以前より小さくなっている。
>
> これに対して後者の目的でメモをとる人は、すべてを書こうとはしない。話の要点だけを短い言葉で書き、矢印や記号で項目どうしの関係を示す。何を書き、何を捨てるかを判断する過程そのものが、内容を考えることになるからである。（　　）、優れたメモは、あとから読み返したときよりも、書いているその場で役に立っているとも言える。

**問1.** 本文の内容と合うものはどれですか。

A 録音が手軽になったため、会議でメモをとる必要はなくなった
B 話の構造を整理するためのメモでは、要点を選んで書くことが大切である
C 話す速さに合わせて書けば、話の流れを見失わずにすむ
D メモの二つの役割のうち、記録としての役割のほうが重要である

**問2.** 本文中の（　　）に入る語として最も適切なものはどれですか。

A しかし　B たとえば　C その意味で　D ところで　E それでも

**問3.** 筆者が「記録のためだけのメモの価値は以前より小さくなっている」と述べるのはなぜですか。

A 録音や議事録を手軽に残せるようになったから
B 人が話す速さが以前より速くなったから
C 会議のあとでメモを読み返す人が減ったから
D 矢印や記号を使ったメモが広まったから

<details>
<summary>解答と解説を見る</summary>

**問1：B。** 第3段落に「話の要点だけを短い言葉で書き」「何を書き、何を捨てるかを判断する過程そのものが、内容を考えることになる」とあります。Aは言いすぎで、本文は「記録のためだけのメモの価値は以前より小さくなっている」と述べているだけです。Cは、本文が「話す速さに書く速さが追いつくことはまずない」と述べているので合いません。Dのように二つの役割の重要度を比べた記述は本文にありません。

**問2：C（その意味で）。** 空欄の前では「何を捨てるか判断することが、内容を考えることになる」と述べ、空欄のあとでは「メモは書いているその場で役に立っている」と言い換えています。前の内容を受けて、別の角度からまとめ直しているので「その意味で」が合います。「しかし」「それでも」は逆の内容をつなぐ語、「たとえば」は例を挙げる語、「ところで」は話題を変える語です。

**問3：A。** 該当する文の前半に「録音や議事録が手軽に残せる今」とあり、これが理由です。B、C、Dはいずれも本文に書かれていません。理由を問う設問では、問われた文の中やその直前に根拠があることが多いので、まずその近くを探しましょう。

</details>

## 自己採点

| 問題 | 1 | 2 | 3 |
|---|---|---|---|
| 正解 | B | C | A |

- **3問正解：** 根拠を本文に求める読み方ができています。
- **2問正解：** 間違えた問題で、選んだ選択肢の根拠を本文の中で指させるか確かめてください。指させなければ、その選択肢は本文にない内容です。
- **1問以下：** 段落ごとに一言メモをとる練習から始めましょう。公式も、日ごろからさまざまな分野の文章を読んでおくことを勧めています。
