# 集合・表の読み取り

**ひとことで言うと：** アンケート結果のような情報を整理して人数を求める「集合」と、表の数字から増加率や割合を読み取る「表の読み取り」の問題です。

どちらも、与えられた情報を**表に整理してから計算する**点が共通しているので、このガイドでは一つのページにまとめています。なお、「集合」「表の読み取り」という名前は市販の問題集でよく使われる呼び方で、公式の区分名ではありません。

## 何を測っているか

非言語分野の「数的な処理ができるか」を見る形式です。計算そのものは簡単で、差がつくのは**どの数字を使うかを正しく選べるか**です。

## 集合は「クロス表」で整理する

「英語を学んでいるか」「中国語を学んでいるか」のように2つの条件がある問題は、ベン図を描く代わりに、次のような2×2の表に整理すると確実です。

| | 中国語を学んでいる | 学んでいない | 合計 |
|---|---|---|---|
| 英語を学んでいる | 両方 | 英語だけ | 英語の合計 |
| 学んでいない | 中国語だけ | どちらもなし | |
| 合計 | 中国語の合計 | | 全体 |

わかっている数字を入れていけば、残りのマスは足し算と引き算で埋まります。覚えておく式は一つだけです。

> 少なくとも一方に当てはまる人数＝Aの人数＋Bの人数－両方に当てはまる人数

## 解き方の手順

**集合**

1. **2×2の表を描く。** 条件が2つなら、上の形をそのまま使います。
2. **問題文の数字を表に入れる。** 「全体」「Aの合計」「Bの合計」「どちらもなし」など、どのマスの数字かを一つずつ確かめます。
3. **空いたマスを足し算と引き算で埋める。** 縦と横の合計が合っているかで検算できます。

**表の読み取り**

1. **問われている指標を確かめる。** 「増加数」か「増加率」か、「何%」か「何倍」か。
2. **必要な列と行だけを使う。** 表のすべての数字を使う問題はほとんどありません。
3. **概算で選択肢を絞ってから計算する。** 選択肢の間隔が広ければ、細かい割り算は要りません。

## よくあるミス

- **両方に当てはまる人を2回数える。** 「A＋B」から両方の人数を引くのを忘れると、人数が多すぎる答えになります。
- **増加数と増加率を取り違える。** 増加した数が最も大きい支店と、増加率が最も大きい支店は同じとは限りません。
- **割合の分母を取り違える。** 「2025年度の合計に占める割合」なら、分母は2025年度の合計です。
- **計算を細かくやりすぎる。** 選択肢が「約20%」「約25%」のように離れていれば、概算で十分です。

## 時間の目安

集合も表の読み取りも1問1分前後を目安にしてください（このガイドの目安で、公式の数字ではありません）。表の問題は同じ表で複数の設問が続くことがあるので、最初に表の見出しを確かめておくと、2問目以降が速くなります。

## 練習問題

この3問は、このガイドのために作ったオリジナル問題です。SPI３の実際の問題や公式の問題例ではありません。

**問1.** 学生100人に、外国語の学習について調べました。英語を学んでいる人は62人、中国語を学んでいる人は25人、どちらも学んでいない人は20人でした。英語と中国語の両方を学んでいる人は何人ですか。

A 5人　B 7人　C 13人　D 18人　E 20人

問2と問3は、次の表を使って答えてください。

ある会社の4つの支店の売上高（単位：百万円）

| 支店 | 2024年度 | 2025年度 |
|---|---|---|
| 北支店 | 240 | 276 |
| 南支店 | 180 | 198 |
| 東支店 | 300 | 324 |
| 西支店 | 150 | 180 |

**問2.** 2024年度から2025年度にかけて、売上高の増加率が最も大きい支店はどれですか。

A 北支店　B 南支店　C 東支店　D 西支店　E 4支店とも同じ

**問3.** 2025年度の4支店の売上高の合計のうち、東支店が占める割合はおよそ何%ですか。

A 約28%　B 約31%　C 約33%　D 約36%　E 約39%

<details>
<summary>解答と解説を見る</summary>

**問1：B（7人）。** 少なくとも一方を学んでいる人は、100－20＝80人です。英語と中国語の人数を足すと62＋25＝87人で、80人より7人多くなります。この7人が、両方を学んでいて2回数えられた人です。

**問2：D（西支店）。** 増加率は「増えた額÷2024年度の額」です。北支店は36÷240＝15%、南支店は18÷180＝10%、東支店は24÷300＝8%、西支店は30÷150＝20%です。増えた額が最も大きいのは北支店の36ですが、増加率では西支店が最も大きくなります。

**問3：C（約33%）。** 2025年度の合計は276＋198＋324＋180＝978です。東支店は324なので、324÷978≒0.331、約33%です。978をおよそ1,000と見て、324÷1,000≒32%より少し大きい値と概算しても約33%を選べます。

</details>

## 自己採点

| 問題 | 1 | 2 | 3 |
|---|---|---|---|
| 正解 | B | D | C |

- **3問正解：** 情報を整理してから計算する手順が身についています。
- **2問正解：** 間違えた問題で、使う数字（分母や、両方の人数）を正しく選べていたかを確かめてください。
- **1問以下：** 問1をクロス表に書き込んで解き直し、表の読み取りでは「増加数」と「増加率」の違いを確かめましょう。
