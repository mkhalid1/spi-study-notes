# 時間配分

パソコンで受けるSPI３には、**問題ごとの制限時間**と**全体の制限時間**の2つがあります。紙のテストのように「難しい問題は飛ばして最後に戻る」という作戦は使えません。このページでは、このしくみに合った時間の使い方をまとめます。

## 公式が説明している時間のしくみ

| 項目 | 公式の説明 |
|---|---|
| 問題ごとの制限時間 | 時間がくると、自動的に次の問題に進む |
| 全体の制限時間 | この時間内に出題される問題数は、人によって異なる |
| 画面の表示 | 受検前の説明で、進捗バーや時計など、画面に表示される情報の見方が案内される |
| 練習問題 | 受検開始前に、言語と非言語の練習問題が1題ずつ出る |
| 検査時間（大卒採用向けSPI３-U） | テストセンター・インハウスCBT・WEBテスティングは65分、ペーパーテスティングは110分（性格検査と基礎能力検査の合計） |
| 検査時間（単独の場合） | 性格検査のみのSPI３-PはインハウスCBT・WEBテスティングで30分、基礎能力検査のみのGAT-UはWEBテスティングで35分 |

出典：[就職準備応援サイト「よくあるご質問について」](https://www.recruit-ms.co.jp/freshers/spi-012.html)、[同「SPIのテストセンターについて」](https://www.recruit-ms.co.jp/freshers/spi-006.html)、[SPI３ 料金詳細（検査時間の表）](https://www.spi.recruit.co.jp/spi3/charge/charge.html)。2026年11月25日に確認。

公式は、問題ごとの制限時間が何秒か、全体で何問出るかは公表していません。

## 基本の考え方

1. **1問ごとに決着をつける。** 次の画面に進むと前の問題には戻れません。公式の就職準備応援サイトも、パソコンでの受検には「次の画面に進むと前の画面には戻れない」独特の形式があると注意しています。
2. **時間切れで進むより、自分で選んで進む。** 問題ごとの制限時間がきて自動で進むと、その問題は無回答のままになりがちです。迷ったら、残った候補から一つ選んで進みましょう。
3. **解けない問題に気持ちを残さない。** 公式も「時間内に解けない問題があっても、気持ちを切り替えて次の問題に集中しましょう」と助言しています。
4. **全部解こうとしない。** 出題数は人によって違うので、他人と比べて焦る必要はありません。公式は「焦ってすべて解こうとせず、解けるものを着実に回答しましょう」としています。

## 問題タイプ別の目安

次の表は、このガイドが練習用に勧める目安です。**公式の数字ではありません。** 本番では画面の表示を優先してください。

| 問題タイプ | 1問の目安 | ひとこと |
|---|---|---|
| [二語の関係](sections/nigo-no-kankei.md) | 20〜30秒 | 手順が決まっているので速く解ける |
| [語句の意味](sections/goku-no-imi.md) | 15〜30秒 | 知らなければ消去法で選んで進む |
| [文の並べ替え](sections/narabekae.md) | 30秒〜1分 | かたまりを作ると速くなる |
| [長文読解](sections/chobun-dokkai.md) | 読むのに2分前後、設問1つに30秒前後 | 設問を先に見る |
| [推論](sections/suiron.md) | 1分〜1分半 | 書き出しに時間をかけすぎない |
| [割合・損益](sections/wariai-soneki.md) | 1分前後 | 筆算を丁寧に |
| [確率・場合の数](sections/kakuritsu.md) | 1分前後 | 書き出しか計算かを先に決める |
| [速さ](sections/hayasa.md) | 1分前後 | 単位をそろえてから |
| [集合・表の読み取り](sections/shugo-hyo.md) | 1分前後 | 概算で選択肢を絞る |

## 時間を失いやすい場面

- **非言語の筆算。** テストセンターでは計算機が使えないので、筆算の速さがそのまま時間に響きます。ふだんの練習から電卓を使わないようにしましょう。
- **推論の書き出し。** 並びを全部書き出そうとして時間を使い切ることがあります。いちばん強い条件から使えば、候補はすぐ減ります。
- **長文の読み直し。** 段落ごとに一言メモをとっておくと、戻る場所がすぐにわかります。
- **受検前の説明画面。** 公式は、操作説明と練習問題を飛ばさず丁寧に確認するよう勧めています。画面の見方や操作がわかっていれば、本番で操作に迷って時間を失うことがなくなります。

## 時間を意識した練習

時間の感覚は、制限時間つきで解いてみないと身につきません。まずこのガイドの練習問題を、目安の時間を意識しながら解いてください。そのうえで、[PrepClubsの無料SPI模擬テスト](https://prepclubs.com/ja/spi-renshu-mondai?utm_source=github&utm_medium=referral&utm_campaign=study-notes&utm_content=spi)のような時間つきの練習で、言語と非言語を通して解く感覚をつかみましょう。PrepClubsの模擬テストは35問を35分で解く練習用の形式で、本番の問題数や時間とは別物です。
