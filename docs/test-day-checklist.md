# 受検当日のチェックリスト

方式ごとに、前日から受検後までに確かめることをまとめました。持ち物や規則は、公式のテストセンター情報とよくある質問にもとづいています。最新の情報は、受検案内のメールと予約完了メールで必ず確かめてください。

## 前日まで

- [ ] 受検案内のメールで、**方式**（テストセンター、WEBテスティングなど）と**受検期限**を確かめた
- [ ] テストセンターなら、会場と日時を予約した
- [ ] テストセンターなら、性格検査を期限（予約操作をした日の27時）までに受けた
- [ ] 英語能力検査や構造的把握力検査があるかを、予約画面で確かめた
- [ ] リアル会場なら、地図を予約完了メールかマイページで確かめた
- [ ] 電卓を使わずに、非言語の練習問題を一度解いておいた

## 持ち物

| 持ち物 | リアル会場 | オンライン会場 |
|---|---|---|
| 顔写真付き本人確認書類（原本・有効期限内） | 必要 | 必要 |
| 受検票 | 必要。予約完了画面を印刷する | 不要 |
| 筆記用具 | 会場で用意される。私物は使えない | シャープペンシルか鉛筆。ボールペンは不可 |
| メモ用紙 | 会場で用意される。私物は使えない | A4の白紙を合計2枚まで |
| パソコン | 不要 | WEBカメラ付き。推奨環境を満たすもの |

- 本人確認書類の例として、公式は運転免許証、パスポート、学生証（プラスチックカード型のみ）、社員証、在留カードなどを挙げています。
- プリンターがない場合は、「テストセンターID」「カナ氏名」「検査名」「会場名」「日程」「ターム」をA4の白紙に書いて持参すれば受検票の代わりになります。
- 計算機は、検査中は使えません。
- 受検料金はかかりません。

出典：[テストセンター 受検の流れ・基本情報](https://www.spi.recruit.co.jp/testcenter/about.html)、[テストセンター よくある質問](https://www.spi.recruit.co.jp/testcenter/faq.html)。2026年11月25日に確認。

## オンライン会場の準備

- [ ] OSとブラウザが推奨環境を満たしている（ブラウザは最新版のGoogle ChromeかMicrosoft Edgeのみ）
- [ ] メモリが4GB以上ある
- [ ] 回線速度が上り・下りとも10Mbps相当以上ある。無線より有線LANが推奨されている
- [ ] WEBカメラが正面から自分を映す位置にある
- [ ] オーディオとマイクがミュートになっていない
- [ ] 静かで、監督者に受検エリアを見せられる場所を用意した

タブレットやスマートフォンでは、オンライン会場の能力検査は受けられません。

## WEBテスティングの準備

- [ ] パソコンで受ける（スマートフォンでは受検できず、タブレットも推奨されていない）
- [ ] 推奨環境を満たしているかを事前に確かめた
- [ ] 期限に余裕をもって、落ち着ける時間と場所を確保した
- [ ] トラブルに備えて、受検案内メールにあるヘルプデスクの連絡先を控えた

## 受検の直前

- [ ] リアル会場には時間に余裕をもって着く。遅刻すると受検できない
- [ ] 操作説明と練習問題（言語と非言語が1題ずつ）を飛ばさずに読む
- [ ] 進捗バーと時計の位置を確かめる

## 受検中

- [ ] 一問ずつ決着をつけて進む。前の問題には戻れない
- [ ] 迷ったら、残った候補から一つ選んで次へ
- [ ] 解けなかった問題は引きずらない
- [ ] 非言語は筆算をメモ用紙に丁寧に書く

## 受検後

- [ ] マイページの受検履歴で、企業への結果送信を確かめる
- [ ] 手応えのよかった・悪かった問題タイプをメモしておく。次の受検までの練習に使う
- [ ] 合否について知りたいときは、受検企業に直接問い合わせる（公式FAQの案内）

## 最後の練習

本番の前に一度、時間を計って通して解いておくと安心です。[PrepClubsの無料SPI模擬テスト](https://prepclubs.com/ja/spi-renshu-mondai?utm_source=github&utm_medium=referral&utm_campaign=study-notes&utm_content=spi)は登録なしで始められます。
