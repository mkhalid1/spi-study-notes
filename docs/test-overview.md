# SPI３とは

SPI３は、リクルートマネジメントソリューションズが提供する適性検査です。働くうえで土台になる知的能力を測る「能力検査」と、人となりを把握する「性格検査」の2つで構成されています。新卒採用では面接の前に実施されることが多く、結果は選考だけでなく、面接での質問づくりや入社後の配属の参考にも使われます。

## 基本データ

| 項目 | 公式情報 |
|---|---|
| 提供元 | 株式会社リクルートマネジメントソリューションズ |
| 名称の由来 | Synthetic Personality Inventory（総合適性検査）の略 |
| 構成 | 能力検査（言語分野・非言語分野）と性格検査。企業によっては英語能力検査や構造的把握力検査が加わる |
| 受検方式 | テストセンター、WEBテスティング、インハウスCBT、ペーパーテスティングの4つ。どれになるかは応募先の企業が決める |
| 検査時間（大卒採用向けSPI３-U） | テストセンター・インハウスCBT・WEBテスティングは65分、ペーパーテスティングは110分（性格検査と基礎能力検査の合計） |
| 問題数 | 公式には公表されていない。パソコンで受ける方式は適応型で、出題数は人によって異なる |
| 合格ライン | 公表されていない。求める水準は企業ごとに異なる |
| 結果の開示 | 受検者本人には開示されない |
| 利用実績 | 年間16,500社、276.6万人（2026年3月期実績） |

出典：[SPI３公式サイト](https://www.spi.recruit.co.jp/)、[SPI３ 料金詳細（検査時間の表）](https://www.spi.recruit.co.jp/spi3/charge/charge.html)、[就職準備応援サイト「適性検査SPIとは？」](https://www.recruit-ms.co.jp/freshers/spi-001.html)、[同「よくあるご質問について」](https://www.recruit-ms.co.jp/freshers/spi-012.html)。2026年11月25日に確認。

## 能力検査と性格検査

| 検査 | 何を測るか | 答え方 |
|---|---|---|
| 能力検査・言語分野 | 言葉の意味や話の要旨を的確にとらえて理解できるか | 語彙、語順の並べ替え、長文などの形式がある |
| 能力検査・非言語分野 | 数的な処理ができるか、論理的に考えられるか | 計算や推論などの形式がある |
| 性格検査 | 日ごろの行動や考え方の傾向（約300問） | 「あてはまる」から「あてはまらない」までの段階で選ぶ。正解はない |

公式の就職準備応援サイトは、能力検査の代表的な問題例として、言語分野から「語彙」と「文章読解」、非言語分野から「計算」と「推論」を紹介しています。このガイドでは、それをさらに細かく次の9つの問題タイプに分けて解説しています。この分け方は市販の問題集でもよく使われる整理で、**公式の区分ではありません**。

| 言語 | 語句の意味 | [語句の意味](sections/goku-no-imi.md) |
| 言語 | 文の並べ替え | [文の並べ替え](sections/narabekae.md) |
| 言語 | 長文読解 | [長文読解](sections/chobun-dokkai.md) |
| 非言語 | 推論 | [推論](sections/suiron.md) |
| 非言語 | 割合・損益 | [割合・損益](sections/wariai-soneki.md) |
| 非言語 | 確率・場合の数 | [確率・場合の数](sections/kakuritsu.md) |

## 適応型テストのしくみ

テストセンターなどパソコンで受ける方式では、IRT（項目反応理論）を使った「適応型テスト」が導入されています。前の問題への回答結果から受検者の能力レベルを推定し、次に最適な問題を選んで出題する方式です。公式はこれを「視力検査のような方法」と説明しています。

このしくみから、受検者にとって大事なことが3つわかります。

1. **出題される問題は人によって違う。** 隣の人と同じ問題が出るとは限りません。
2. **出題数も人によって違う。** 公式は「全体の制限時間」内に出題される問題数は人によって異なると明言しています。
3. **難しい問題が出た、長文が出た、というだけで合否はわからない。** 公式は「長文が出たからといって合格ラインに達しているわけではない」と説明しています。

リクルートマネジメントソリューションズは1999年に、この適応型テストを日本で初めてCBT（Computer-Based Testing）として実用化したと説明しています。

出典：[就職準備応援サイト「SPIの開発背景と理念」](https://www.recruit-ms.co.jp/freshers/spi-013.html)、[同「よくあるご質問について」](https://www.recruit-ms.co.jp/freshers/spi-012.html)

## SPI、SPI2、SPI３の関係

公式によると、SPIは1974年に誕生しました。前身となるテストの開発は1963年に始まっており、その後、時代の変化に合わせてSPI、SPI2、SPI３と改訂されてきました。いま企業が使っているのがSPI３です。就活生の会話で「SPI」と言うときは、ほぼこのSPI３を指しています。

対象者別にテストの種類が分かれており、大卒採用向け、中途採用向け、高卒採用向けがあります。大卒採用向けのSPI３-Uには、英語能力検査や構造的把握力検査を組み合わせた種類もあります。

## 対策について公式が言っていること

最初に知っておいてほしいのは、公式の立場です。

- 能力検査は「暗記や受検対策によって簡単に得点が上がるものではなく、長期の日常的な努力によって培われるもの」と説明されています。
- 対策本で事前学習をしても能力検査の得点には影響がないことを、実験で確認していると述べています。
- そのうえで、受検前の準備として「パソコンでの受検に慣れておく」「問題の形式を把握しておく」の2つを勧めています。
- 公式のSPI対策本はありません。書店に並ぶ対策本は、リクルートマネジメントソリューションズが公認したものではありません。

このガイドもその考え方に沿っています。裏技で点数を上げるのではなく、**形式を知り、解き方の手順を決めておくことで、本番で実力どおりに解き切る**ことが目的です。初めて見る形式に焦って時間を失うのが、いちばんもったいない失点だからです。

出典：[就職準備応援サイト「SPIの能力検査とは？」](https://www.recruit-ms.co.jp/freshers/spi-003.html)、[SPI３ 特長（よくある質問）](https://www.spi.recruit.co.jp/spi3/features/)、[就職準備応援サイト「よくあるご質問について」](https://www.recruit-ms.co.jp/freshers/spi-012.html)

## 形式に慣れておく

形式に慣れるいちばんの近道は、制限時間つきで一度通して解いてみることです。[PrepClubsの無料SPI模擬テスト](https://prepclubs.com/ja/spi-renshu-mondai?utm_source=github&utm_medium=referral&utm_campaign=study-notes&utm_content=spi)は、言語と非言語を合わせた練習用の35問を35分で解く形式です。本番の問題数や時間とは別物ですが、時間に追われる感覚をつかむ練習になります。
