# 用語集

SPI３の案内メールや公式ページ、このガイドに出てくる言葉を五十音順にまとめました。

| 用語 | 意味 |
|---|---|
| インハウスCBT | 応募先の企業に出向き、企業のパソコンで受ける方式 |
| WEBテスティング | 自宅や学校など、インターネットにつながる場所のパソコンで受ける方式。テストセンターのオンライン会場とは別物 |
| 英語能力検査 | 企業によって加わる検査。語彙、穴埋め、長文読解などが出題され、リスニングやスピーキングはない |
| オンライン会場 | テストセンターの会場の一つ。自宅などのパソコンで、画面越しに監督者とつないで受ける |
| 仮予約 | テストセンターの会場予約の手続き中の状態。性格検査を期限までに受けると予約が確定する |
| 企業別受検ID | 企業ごとに発行される、受検手続きのためのID。受検案内メールに書かれている |
| 基礎能力検査 | 言語分野と非言語分野からなる能力検査。単に「能力検査」とも呼ばれる |
| 組み合わせ | 順番を区別せずに選ぶ選び方 |
| 原価 | 店が品物を仕入れた値段。仕入れ値とも言う |
| 言語分野 | 言葉の意味や話の要旨を的確にとらえて理解できるかを測る分野 |
| 構造的把握力検査 | 企業によって加わる検査。ものごとの背後にある共通性や関係性を構造的にとらえる力を測る |
| 受検票 | リアル会場で必要な書類。受検予約完了画面を印刷したもの |
| 順列 | 順番や役割を区別して並べる選び方 |
| 性格検査 | 日ごろの行動や考え方についての約300問に答える検査。正解はない |
| 前回結果送信 | テストセンターで過去1年以内に受けた直近の結果を、別の企業に送る機能 |
| 定価 | 店が最初につけた値段 |
| 適応型テスト | 前の問題への回答結果をもとに、次の問題を選んで出題するテスト。パソコンで受ける方式に導入されている |
| テストセンター | リクルートマネジメントソリューションズが運営する会場（リアル会場・オンライン会場）で、監督者のもと受ける方式 |
| テストセンターID | テストセンターを初めて使うときに取得する、自分専用のID。ほかの企業で受けるときにも使う |
| 非言語分野 | 数的な処理ができるか、論理的思考力があるかを測る分野 |
| ペーパーテスティング | 企業が用意した会場で、マークシートで受ける方式 |
| マイページ | テストセンターの予約状況や受検履歴を確認できるページ。URLは予約完了メールなどに書かれている |
| もとにする量 | 割合を求めるときの基準になる量。「原価の3割」なら原価 |
| 余事象 | 「ある出来事が起こらない」場合。「少なくとも1つ」の確率は、1から余事象の確率を引いて求める |
| リアル会場 | テストセンターの会場の一つ。全国の会場に出向いて受ける |
| IRT（項目反応理論） | 適応型テストの土台になっている測定の理論 |
| SPI３-U | 大卒採用向けのSPI３。性格検査と基礎能力検査からなる |

用語の説明は、[SPI３公式サイト](https://www.spi.recruit.co.jp/)と[就職準備応援サイト](https://www.recruit-ms.co.jp/freshers/spi-001.html)の説明を、このガイドの言葉でまとめたものです。計算の用語は一般的な意味で説明しています。
