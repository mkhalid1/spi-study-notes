# 学習プラン（7日・2日）

1週間あるときの7日プランと、受検案内がもう届いているときの2日プランを用意しました。どちらも、最初に[15分診断テスト](diagnostic.md)で苦手な問題タイプを見つけてから始めます。7日プランは1日45分から90分が目安です。

公式は、能力検査の得点は短期間の対策で大きく変わるものではないとしたうえで、受検前に「パソコンでの受検に慣れておく」「問題の形式を把握しておく」ことを勧めています。このプランもその考え方に沿って、**形式に慣れること**と**時間内に落ち着いて解き切ること**を目標にしています。

## 7日プラン

| 日 | テーマ | やること |
|---|---|---|
| 1日目 | 全体をつかむ | [SPI３とは](test-overview.md)と[4つの受検方式](formats.md)を読み、自分が受ける方式を確かめる。[15分診断テスト](diagnostic.md)を解き、苦手なタイプを2つ書き出す |
| 2日目 | 言語（語彙） | [二語の関係](sections/nigo-no-kankei.md)と[語句の意味](sections/goku-no-imi.md)を読み、各ページの3問を解く。間違えた問題は下の見直し方で記録する |
| 3日目 | 言語（文章） | [文の並べ替え](sections/narabekae.md)と[長文読解](sections/chobun-dokkai.md)を読み、各3問を解く。長文は段落メモをとりながら読む |
| 4日目 | 非言語（論理） | [推論](sections/suiron.md)の3問と[集合・表の読み取り](sections/shugo-hyo.md)の3問を解く。条件はすべて記号で書き出す |
| 5日目 | 非言語（計算） | [割合・損益](sections/wariai-soneki.md)、[確率・場合の数](sections/kakuritsu.md)、[速さ](sections/hayasa.md)の計8問を、電卓なしで解く |
| 6日目 | 通しの練習 | [PrepClubsの無料SPI模擬テスト](https://prepclubs.com/ja/spi-renshu-mondai?utm_source=github&utm_medium=referral&utm_campaign=study-notes&utm_content=spi)のような時間つきの練習を通して解く。[時間配分](timing.md)を読み、時間を失った問題タイプを確かめる |
| 7日目 | 仕上げ | 間違えた問題の記録の「次に確かめること」を読み返す。苦手タイプの練習問題を、答えを見ずに解き直す。[受検当日のチェックリスト](test-day-checklist.md)を確認し、夜は早めに休む |

### 間違えた問題の見直し方

点数が伸びるのは、解いた数より見直しの質です。間違えた問題ごとに、次の3つを1行ずつ書いてください。

1. **どの手順を飛ばしたか。** 例：「左右の順番を確かめなかった」「もとにする量を取り違えた」「並びを全部書き出さなかった」
2. **問題文のどこで気づけたか。** 例：「『すぐ後』という言葉」「『少なくとも』という言葉」
3. **次に確かめること。** 例：「二語の関係は必ず文にしてから比べる」

これを1か所にまとめておくと、6日目ごろには同じミスが2つか3つに絞られてきます。そこを直すのが、いちばん効率のよい仕上げです。

## 2日プラン

受検案内が届いて、受検期限が迫っているときのプランです。テストセンターは、受検のピーク時期や期限の間際には会場が混み合うと公式が注意しています。**まず会場を予約してから**勉強を始めてください。

### 1日目：形式を知る

| ブロック | 時間 | やること |
|---|---|---|
| 1 | 10分 | 受検案内のメールで方式と期限を確かめる。テストセンターなら会場を予約し、性格検査を期限までに受ける |
| 2 | 15分 | [15分診断テスト](diagnostic.md)を解く |
| 3 | 30分 | 9つのページの「問題の形」と「よくあるミス」だけを読む |
| 4 | 40分 | 診断で間違えたタイプのページを読み、練習問題を解く |

### 2日目：時間内に解く

| ブロック | 時間 | やること |
|---|---|---|
| 1 | 40分 | [PrepClubsの無料SPI模擬テスト](https://prepclubs.com/ja/spi-renshu-mondai?utm_source=github&utm_medium=referral&utm_campaign=study-notes&utm_content=spi)を時間を計って通して解く |
| 2 | 30分 | 間違えた問題タイプのページで、手順を読み直す |
| 3 | 10分 | [時間配分](timing.md)の「基本の考え方」を読む |
| 4 | 10分 | [受検当日のチェックリスト](test-day-checklist.md)で持ち物と流れを確かめる |

## やらないほうがいいこと

- **前日の夜遅くまで詰め込む。** 本番で必要なのは、知識の量より落ち着いて読む力です。
- **性格検査の「正解」を探す。** 公式は、取り繕わずに率直に答えるよう勧めています。詳しくは[性格検査](personality.md)のページを読んでください。
- **電卓を使って練習する。** テストセンターでは計算機を使えません。筆算の速さも練習のうちです。
- **ネットの「合格ライン」の数字を気にする。** 公式は合格の基準を公表していません。理由は[結果の見られ方](scoring.md)にまとめています。
