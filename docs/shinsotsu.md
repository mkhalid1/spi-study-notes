# 新卒就活生のためのSPIガイド

就職活動を進めていると、SPI３の受検案内は一度ならず届くはずです。公式の就職準備応援サイトも、SPIを「就職活動を進めていくと、一度は受ける可能性が高いテスト」と紹介しています。このページでは、新卒の就活生がつまずきやすい、**問題を解く前の段取り**をまとめます。

## 選考のどこでSPIを受けるか

公式の大卒採用向けページによると、SPI３は面接の前に実施されることが多い検査です。企業は結果を、1次面接に進む応募者を絞り込む材料にしたり、面接での質問を事前に考える材料にしたりしています。

つまり、SPIは**面接の前の関門**であると同時に、**面接の準備資料**でもあります。性格検査の結果をもとに、面接で「こういう場面ではどうしますか」と聞かれることもありえます。取り繕わずに答えておくほうが、面接で自分の言葉と結果が食い違わずにすみます。

出典：[SPI３ 大卒採用向け](https://www.spi.recruit.co.jp/spi3/service/spi3_u.html)、[就職準備応援サイト「SPIの性格検査とは？」](https://www.recruit-ms.co.jp/freshers/spi-002.html)。2026年11月25日に確認。

## 受検の時期と予約

テストセンターの受検ピークは3月から6月です。この時期は常設会場のほかに、全国の主要都市に臨時会場が設けられます。それでも会場は大変混み合うので、公式は受検依頼のメールが届いたらすぐに空席を確認するよう勧めています。

予約まわりのルールで、知っておくと助かるものをまとめました。

| ルール | 内容 |
|---|---|
| 予約の締め切り | 空きがあれば、当日の各ターム開始1時間前まで予約できる |
| 予約の変更・取り消し | 当日の各ターム開始1時間前まで。それ以降は画面上で取り消せない |
| 性格検査の期限 | 会場の予約操作をした日の27時（翌日午前3時）まで。間に合わないと仮予約は取り消される |
| 遅刻 | 遅刻すると受検できない |
| 欠席 | 欠席が2回になると、受検の予約や前回結果送信ができなくなる |
| 予約の手段 | パソコンかスマートフォン。電話での予約は受け付けていない |

近くの会場が混んでいて予約しにくいときは、リアル会場とオンライン会場のうち空いているほうを使うよう公式は案内しています。どちらで受けても、結果は同じように扱われます。

出典：[テストセンター 受検の流れ・基本情報](https://www.spi.recruit.co.jp/testcenter/about.html)、[テストセンター よくある質問](https://www.spi.recruit.co.jp/testcenter/faq.html)、[SPI３ よくある質問](https://www.spi.recruit.co.jp/spi3/faq/)

## 前回結果送信を上手に使う

テストセンターでは、過去1年以内に受けた結果を、別の企業に送ることができます。公式によると、面接開始のピーク前には、受検者の半数近くが前回結果送信を使っています。

知っておきたい点は4つです。

1. **送れるのは直前に受けた結果だけ。** 何回受けていても、過去の結果から選ぶことはできません。
2. **自分の得点はわからない。** 送る結果が良かったかどうかは、受検者には知らされません。
3. **企業には、新たに受けたか前回結果を送ったかは知らされない。**
4. **検査ごとに選べる。** 性格検査だけ前回結果を送り、能力検査は受け直す、といった組み合わせもできます。

そのため、**最初の数回の受検をしっかり準備して臨む**ことが、その後の就活全体の負担を軽くします。手応えがなかったときは、次の企業では受け直すこともできます。どちらにするかは、自分のスケジュールと手応えで決めてください。

出典：[就職準備応援サイト「SPIのテストセンターについて」](https://www.recruit-ms.co.jp/freshers/spi-006.html)、[同「よくあるご質問について」](https://www.recruit-ms.co.jp/freshers/spi-012.html)

## 英語や構造的把握力が出る企業もある

企業によっては、能力検査に英語能力検査や構造的把握力検査が加わります。実施するかどうかは企業ごとに違い、受検予約の際に画面で確認できます。実施しない企業では、受ける必要はなく、受けることもできません。

公式によると、英語能力検査は語彙、穴埋め、長文読解などが中心で、リスニングやスピーキングはありません。構造的把握力検査は、ものごとの背後にある共通性や関係性を構造的にとらえる力を測る検査です。このガイドは言語・非言語の基礎能力検査を中心に扱っています。

## 服装と当日の雰囲気

テストセンターに服装の指定はなく、スーツでなくてもかまいません。公式は、テストセンターは企業の選考の場ではなくテストを受けるための場で、人事担当者が会場で受検者の様子を確認することはない、と説明しています。リラックスできる服装で行きましょう。

## 練習をどこで始めるか

段取りがわかったら、あとは形式に慣れるだけです。[15分診断テスト](diagnostic.md)で苦手を見つけ、[学習プラン](study-plans.md)に沿って進めてください。時間つきの通し練習には、[PrepClubsの無料SPI模擬テスト](https://prepclubs.com/ja/spi-renshu-mondai?utm_source=github&utm_medium=referral&utm_campaign=study-notes&utm_content=spi)が使えます。
