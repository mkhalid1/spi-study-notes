# SPI３ 対策ノート

SPI３（リクルートマネジメントソリューションズの適性検査）の無料の学習ガイドです。検査のしくみ、4つの受検方式、言語・非言語の9つの問題タイプごとの解き方、解説付きのオリジナル練習問題35問、結果の見られ方、7日と2日の学習プランをまとめています。主な読者は新卒の就活生で、テストセンターの予約や前回結果送信など、問題を解く前の段取りを説明した[専用ページ](docs/shinsotsu.md)もあります。SPI３の事実は、提供元の公式ページだけを出典にしています（[出典一覧](docs/sources.md)）。

まず実力を確かめたい方は、[PrepClubsの無料SPI模擬テスト](https://prepclubs.com/ja/spi-renshu-mondai?utm_source=github&utm_medium=referral&utm_campaign=n7vq4g&utm_content=spi)（35問・35分）か、このガイドの[15分診断テスト](docs/diagnostic.md)から始めてください。

## はじめに

1. **苦手を見つける。** [15分診断テスト](docs/diagnostic.md)を解きます。9つの問題タイプから1問ずつ出題し、どこから始めればよいかがわかります。
2. **苦手なタイプから直す。** 下の表からそのタイプのページを開き、解き方の手順を読んでから、練習問題（各ページ2〜3問）を解きます。
3. **プランに沿って進める。** 時間があれば[7日プラン](docs/study-plans.md#7日プラン)、受検案内がもう届いているなら[2日プラン](docs/study-plans.md#2日プラン)を使ってください。

## 基本データ

| 項目 | 公式情報 |
|---|---|
| 提供元 | 株式会社リクルートマネジメントソリューションズ |
| 構成 | 能力検査（言語分野・非言語分野）と性格検査。企業によって英語能力検査、構造的把握力検査が加わる |
| 受検方式 | テストセンター（リアル会場・オンライン会場）、WEBテスティング、インハウスCBT、ペーパーテスティング |
| 検査時間（大卒採用向けSPI３-U） | パソコンの3方式は65分、ペーパーテスティングは110分（性格検査と基礎能力検査の合計） |
| 問題数 | 公表されていない。パソコンで受ける方式は適応型で、出題数は人によって異なる |
| 制限時間 | 問題ごとの制限時間と、全体の制限時間がある |
| 合格ライン | 公表されていない。企業ごとに基準が異なる |
| 結果の開示 | 受検者本人には開示されない |
| 前回結果送信 | テストセンターでは、過去1年以内の直近の結果を別の企業に送れる |
| 利用実績 | 年間16,500社、276.6万人（2026年3月期実績） |

出典：[SPI３公式サイト](https://www.spi.recruit.co.jp/)、[SPI３ 料金詳細（検査時間の表）](https://www.spi.recruit.co.jp/spi3/charge/charge.html)、[就職準備応援サイト「よくあるご質問について」](https://www.recruit-ms.co.jp/freshers/spi-012.html)ほか。2026年11月25日に確認。

## 9つの問題タイプ

| 分野 | 問題タイプ | 問われること | 練習問題 | ページ |
|---|---|---|---|---|
| 言語 | 二語の関係 | 2つの言葉の関係を見抜き、同じ関係の組を選ぶ | 3問 | [二語の関係](docs/sections/nigo-no-kankei.md) |
| 言語 | 語句の意味 | 説明に合う語や、同じ意味で使われている語を選ぶ | 3問 | [語句の意味](docs/sections/goku-no-imi.md) |
| 言語 | 文の並べ替え | 語句や文を意味の通る順に並べる | 3問 | [文の並べ替え](docs/sections/narabekae.md) |
| 言語 | 長文読解 | 文章の内容、空欄に入る語、理由を答える | 3問 | [長文読解](docs/sections/chobun-dokkai.md) |
| 非言語 | 推論 | 条件から、必ず正しいと言えることを導く | 3問 | [推論](docs/sections/suiron.md) |
| 非言語 | 割合・損益 | 割引、利益、全体に占める割合を計算する | 3問 | [割合・損益](docs/sections/wariai-soneki.md) |
| 非言語 | 確率・場合の数 | 何通りあるか、起こる確率はいくらかを求める | 3問 | [確率・場合の数](docs/sections/kakuritsu.md) |
| 非言語 | 速さ | 道のり・速さ・時間、出会いと追いつき | 2問 | [速さ](docs/sections/hayasa.md) |
| 非言語 | 集合・表の読み取り | 人数を整理し、表から増加率や割合を読む | 3問 | [集合・表の読み取り](docs/sections/shugo-hyo.md) |

9つの分け方は市販の問題集でもよく使われる整理で、公式の区分ではありません。公式は能力検査を「言語分野」と「非言語分野」に分け、問題例として語彙、文章読解、計算、推論などを紹介しています。どのページも、何を測っているか、問題の形、解き方の手順、よくあるミス、時間の目安、練習問題と解説、自己採点表という同じ構成です。

## このガイドの使い方

- **GitHub上でそのまま読めます。** どのページにも「前へ」「次へ」と目次へのリンクがあるので、本のように最初から順に読み進められます。
- **答えを見る前に、自分の答えを決めてください。** 解答は「解答と解説を見る」を開くと表示されます。
- **正解した問題の解説も読んでください。** 多くの解説は、紛らわしい選択肢がなぜ違うのかまで説明しています。そこに一番の学びがあります。
- **間違いを記録しましょう。** 間違えた問題ごとに、飛ばした手順を1行で書いておきます。やり方は[学習プラン](docs/study-plans.md#間違えた問題の見直し方)にあります。
- **時間を計って練習しましょう。** このガイドで解き方を学び、[PrepClubsの無料SPI模擬テスト](https://prepclubs.com/ja/spi-renshu-mondai?utm_source=github&utm_medium=referral&utm_campaign=n7vq4g&utm_content=spi)のような時間つきの練習でペースをつかみます。
